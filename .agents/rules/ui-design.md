# UI Design Guidelines (Web App)
When generating UI code, ALWAYS adhere to these premium design principles:
1. **Rich Aesthetics**: The user must be WOWED at first glance. Use glassmorphism, subtle drop shadows, and modern color palettes.
2. **Dynamic Elements**: Every interactive element should have a smooth hover state. Use micro-animations (e.g., `transition-all duration-300`).
3. **Typography**: Use modern fonts like Inter or Outfit. Avoid default browser fonts.
4. **Layouts**: Prefer CSS Grid and Flexbox for clean, responsive, card-based layouts. 
5. **No Placeholders**: Try to use real contextually relevant data or placeholder images (e.g., from Unsplash) if absolutely needed.
6. **Dark/Light Theme**: If not explicitly specified, default to a modern sleek aesthetic (e.g., a clean light mode with deep contrast or a premium dark mode).
